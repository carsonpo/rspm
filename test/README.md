# test

Run everything with `node tools/test.js [filter]` (Bun works too). Each
`*.test.js` file exports its tests as plain functions.

## Vectors for code we implement ourselves

Argon2id, BLAKE2b, ML-KEM-768, SHA3/SHAKE, and the PoW SHA-256 loop are our own
code (PROTOCOL §2.2), so each is checked against two independent sources:

1. **Official vectors** from the spec: RFC 9106 (Argon2), RFC 7693 (BLAKE2b),
   NIST ACVP (ML-KEM, SHA3/SHAKE), FIPS 180-4 (SHA-256).
2. **Differential vectors** generated by a reputable reference implementation at
   a **pinned version**, so anyone can reproduce them:

   | Primitive | Reference | Pinned in |
   |---|---|---|
   | ML-KEM-768 | Go standard library `crypto/mlkem` (FIPS 140-3 module), plus NIST ACVP-Server vectors at a pinned commit | `gen/go.mod` (`go 1.26.0`) |
   | SHA3 / SHAKE | Go standard library `crypto/sha3` | same |
   | Argon2id, BLAKE2b | `golang.org/x/crypto/argon2`, `/blake2b` | `gen/go.mod` + `gen/go.sum` |

   Coverage is exhaustive across parameter edge cases and wide across random
   inputs: thousands of seeded KeyGen/Encaps/Decaps triples, including tampered
   ciphertexts to test ML-KEM's implicit rejection; Argon2id across memory,
   iteration, and length boundaries; and SHA3/SHAKE at every block-boundary
   length.

ML-KEM encapsulation is randomized in Go, so the generator runs our JS
encapsulation (`gen/mlkem-encaps.mjs`) on seeded inputs and fails unless Go's
decapsulation agrees on every shared secret. Generating therefore needs `node`
on PATH.

`gen/` is development tooling only. It runs with Go, writes JSON into
`vectors/`, and is never part of what ships. The vectors are committed, so
running the tests needs nothing but a JS runtime. To regenerate them:

```sh
cd test/gen && GOTOOLCHAIN=go1.26.0 go run . && git diff --stat ../vectors   # must be empty for a release
```

`vectors/` also holds the RSPM vectors for every derivation in PROTOCOL.md (salt,
subkeys, locators, block encryption, generation search, PoW). Any other
implementation of the protocol should pass them.
